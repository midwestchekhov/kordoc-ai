# jokbo-tool

족보 HWP·HWPX → 본문·급분바 마크다운 + 문제은행 JSON.

## 처음 한 번
```bash
cd jokbo-tool && npm install
```

## 쓰기
```bash
node jokbo.mjs "../소흡/필족(hwpx)" "../소흡/필족(hwp)"          # 폴더 여러 개도 됨
node jokbo.mjs "../소흡/필족(hwp)/어떤족보.hwp" -o ../소흡/변환결과  # 파일 하나, 출력 폴더 지정
```
출력 기본값은 첫 입력 옆의 `변환결과/`. 족보마다 폴더 하나.

파싱·출력은 늘 전부(필족 본문 포함). 무엇을 먼저 읽을지는 `구성.json` 의 `read_order`: 급분바가 잡히면 `급분바.md`·`문족.md` 를 먼저, 본문은 필요할 때만. 급분바가 안 잡히면 `fallback: true` 이고 `본문.md` 가 정리 자리를 대신한다.

| 파일 | 내용 |
|---|---|
| 구성.json | 장마다 갈래(머리말·본문·요약·기출·연습)와 판정 근거(제목·내용), 글 길이·문항 줄·그림 수, 어느 출력에 들어갔는지, `read_order`·`fallback` |
| 머리말.md | 표지·족원 말·출제 경향 표·학습목표 |
| 급분바.md | 요약 장 전부(급분바·앞분바·끕분바·Summary 등) |
| 문족.md | 기출·연습 문제 장을 읽기용으로 |
| 문제은행.json | 문항(발문·선지·정답·해설·그림·장) + meta(과목·수업·교수님·연도·시험·반복 묶음) + 빈 analysis. 다른 장에 섞인 문항 표도 뽑는다 |
| 본문.md | 필족 본문 장 |
| 전체.md | 장 구분 없이 문서 전체 |
| 강조.json | 모든 장의 강조 조각: level 3 王 / 2 빨강·형광펜 / 1 굵게 / 0 곁말(회색) |
| 그림목록.json | 장·문항의 그림마다 주변 글·강조/넘어감 판정 |
| images/ | md 가 쓰는 그림, 긴 변 1600px webp |

마크다운 표기: 빨강 `<r>…</r>`, 형광펜 `==…==`, 회색 `<g>…</g>`, 곁말 문단 `> [곁말] …`.

## 장 나누기·갈래 (`lib/sections.mjs`)
- 장 제목: 1행 2열 표 `| Ⅰ | 제목 |`. 그런 표가 하나도 없으면 문단 "Ⅰ. 제목".
- 갈래는 제목 글자로 정하고 순서는 따지지 않는다(앞분바, 급분바 뒤 끕분바·확인 문제 모두 됨).
  - 요약: "분바" 꼴 낱말(급분바·끕분바·앞분바·X분바·끕쁀뺘·폰본바…, 자모로 본다), 요약·핵심 정리·Summary
  - 연습: 확인·자작·예상·연습 문제, 퀴즈 / 기출: 문족·기출 / 그 밖: 본문
- 제목으로는 본문인데 문항 표(오른칸에 "정답")가 장의 표 절반 이상이면 기출로 고친다(`decided_by: content`).
- 시험: `npm test` (변형 이름·배치 7가지).

필요: Node 22. 엔진은 npm `kordoc`(본문), `@rhwp/core`(HWP 글자 색 읽기용 HWPX 변환), `sharp`(그림 줄이기), `jszip`.

Claude 스킬로 쓰려면 `skill/SKILL.md` 를 스킬로 저장한다(도구를 부르는 법과 결과로 공부하는 법).
