# jokbo-tool

족보 HWP·HWPX → 본문·급분바 마크다운 + 문제은행 JSON.

## 처음 한 번
```bash
cd jokbo-tool && npm install
```

## 쓰기
```bash
node jokbo.mjs "../소흡/필족(hwpx)" "../소흡/필족(hwp)"          # 폴더 여러 개도 됨
node jokbo.mjs "../소흡/필족(hwp)/어떤족보.hwp" -o ../소흡/변환결과  # 파일 하나, 출력 폴더 지정
```
출력 기본값은 첫 입력 옆의 `변환결과/`. 족보마다 폴더 하나:

| 파일 | 내용 |
|---|---|
| 머리말.md·본문.md·급분바.md | 장(Ⅰ·Ⅱ…)별로 나눈 마크다운. 슬라이드 상자 표는 글로 풂 |
| 전체.md | 나누기 전 kordoc 원본 |
| 문제은행.json | 문항(발문·선지·정답·해설·그림) + meta(과목·수업·교수님·연도·시험·반복 묶음) + 빈 analysis |
| 강조.json | 강조 조각: level 3 王 / 2 빨강·형광펜 / 1 굵게 / 0 곁말(회색) |
| 그림목록.json | 그림마다 장·주변 글·강조/넘어감 판정 |
| images/ | 긴 변 1600px webp |

마크다운 표기: 빨강 `<r>…</r>`, 형광펜 `==…==`, 회색 `<g>…</g>`, 곁말 문단 `> [곁말] …`.

필요: Node 22. 엔진은 npm `kordoc`(본문), `@rhwp/core`(HWP 글자 색 읽기용 HWPX 변환), `sharp`(그림 줄이기), `jszip`.

Claude 스킬로 쓰려면 `skill/SKILL.md` 를 스킬로 저장한다(도구를 부르는 법과 결과로 공부하는 법).
