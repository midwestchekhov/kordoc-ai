# jokbo-tool

족보 HWP·HWPX → 본문·급분바 마크다운 + 문제은행 JSON.

## 처음 한 번
```bash
cd jokbo-tool && npm install
```

## 쓰기
```bash
node jokbo.mjs "../소흡/필족(hwpx)" "../소흡/필족(hwp)"          # 폴더 여러 개도 됨
node jokbo.mjs "../소흡/필족(hwp)/어떤족보.hwp" -o ../소흡/변환결과  # 파일 하나, 출력 폴더 지정
```
출력 기본값은 첫 입력 옆의 `변환결과/`. 족보마다 폴더 하나(이름은 NFC 로 맞춘다: Mac 파일 이름의 NFD 한글도 셸에서 바로 맞는다).

### 여러 개 한꺼번에
```bash
node jokbo.mjs "../소흡/필족(hwpx)" -o ../소흡/변환결과 --jobs 2 --budget 170   # 170초 안에서 할 만큼, 다시 돌리면 이어서
node jokbo.mjs ... --timeout 150          # 한 족보의 한 단계가 150초를 넘으면 끊고 다음으로
node jokbo.mjs ... --step questions       # 그 단계만 (convert·questions·recurrence)
node jokbo.mjs ... --force                # 끝난 것도 다시
```
- 단계: convert(md·강조·그림·표) → questions(문제은행·그림 목록) → recurrence(해마다 나온 문항 묶기, 그 족보만).
- 족보마다 `상태.json` 에 단계별 완료·걸린 초·오류를 적고, 마지막 단계까지 끝나야 `done: true`. 원본(크기·수정 시각)이 같고 끝난 단계는 건너뛴다.
- 끝날 때 끝·남음·실패를 표로 보이고, 종료 코드는 모두 끝 0 · 남은 것 있음 2 · 실패 있음 1. 남은 게 있으면 같은 명령을 다시 돌린다.
- 셸 호출 하나가 정해진 시간 안에 끝나야 하는 곳(Cowork 셸 180초)에서는 `--budget` 을 그보다 조금 짧게 준다. 백그라운드로 돌리면 호출이 끝날 때 같이 죽는다.

### 티로 노트 붙이기 (선택)
티로를 쓰는 사람만. 노트를 노트 하나에 파일 하나(.md·.txt·.json)로 폴더에 내려 두고:
```bash
node jokbo.mjs ... --tiro ../소흡/티로노트     # 변환과 함께
node jokbo.mjs --tiro ../소흡/티로노트 -o ../소흡/변환결과   # 이미 변환된 결과에 붙이기만
```
노트 제목("8교시 조민수 교수님")·날짜(.json 의 createdAt 은 KST 로, .md 는 front matter `date:` 나 파일 이름의 20261124)로, 교수님이 같고 교시나 날짜가 맞는 강의 폴더에 `티로_강조.md`(강조로 보이는 줄 + 노트 전문)를 쓴다. 못 맞춘 노트는 끝에 목록으로 알린다. `--tiro` 를 안 주면 이 단계는 없다.

파싱·출력은 늘 전부(필족 본문 포함). 무엇을 먼저 읽을지는 `구성.json` 의 `read_order`: 급분바가 잡히면 `급분바.md`·`문족.md` 를 먼저, 본문은 필요할 때만. 급분바가 안 잡히면 `fallback: true` 이고 `본문.md` 가 정리 자리를 대신한다.

| 파일 | 내용 |
|---|---|
| 구성.json | 장마다 갈래(머리말·본문·요약·기출·연습)와 판정 근거(제목·내용), 글 길이·문항 줄·그림 수, 어느 출력에 들어갔는지, `read_order`·`fallback` |
| 머리말.md | 표지·족원 말·출제 경향 표·학습목표 |
| 급분바.md | 요약 장 전부(급분바·앞분바·끕분바·Summary 등) |
| 문족.md | 기출·연습 문제 장을 읽기용으로 |
| 문제은행.json | 문항(발문·선지·정답·해설·그림·장) + meta(과목·수업·교수님·연도·시험·반복 묶음) + 빈 analysis. 다른 장에 섞인 문항 표도 뽑는다 |
| 본문.md | 필족 본문 장 |
| 전체.md | 장 구분 없이 문서 전체 |
| 강조.json | 모든 장의 강조 조각: level 3 王 / 2 빨강·형광펜 / 1 굵게 / 0 곁말(회색). 王 만 있는 조각은 그 문단 전체(`scope: paragraph`), 응원·인사 같은 잡음은 뺀다 |
| 강조요약.json | level 3·2 강조마다 그것이 걸린 문단·표 전체(王 제목이면 그 아래 몇 블록까지)와 그 안의 그림. `negative` 는 "시험에 안 나옴" 같은 말 |
| 표.md·표목록.json | 장 제목·문항 표를 뺀 표마다 병합 칸을 푼 Markdown 표, 장, 강조 점수(王 3·빨강 2·굵게 1 합), 그림 |
| 상태.json | 단계별 완료·걸린 초·오류, `done` |
| 티로_강조.md | `--tiro` 를 줬을 때만 |
| 그림목록.json | 장·문항의 그림마다 주변 글·강조/넘어감 판정 |
| images/ | md 가 쓰는 그림, 긴 변 1600px webp |

마크다운 표기: 빨강 `<r>…</r>`, 형광펜 `==…==`, 회색 `<g>…</g>`, 곁말 문단 `> [곁말] …`.

## 장 나누기·갈래 (`lib/sections.mjs`)
- 장 제목: 1행 2열 표 `| Ⅰ | 제목 |`. 그런 표가 하나도 없으면 문단 "Ⅰ. 제목".
- 갈래는 제목 글자로 정하고 순서는 따지지 않는다(앞분바, 급분바 뒤 끕분바·확인 문제 모두 됨).
  - 요약: "분바" 꼴 낱말(급분바·끕분바·앞분바·X분바·끕쁀뺘·폰본바…, 자모로 본다), 요약·핵심 정리·Summary
  - 연습: 확인·자작·예상·연습 문제, 퀴즈 / 기출: 문족·기출 / 그 밖: 본문
- 문항 표 줄: 2칸 표에서 오른칸이 "정답" 으로 시작하고 그 뒤에 답이 있는 줄. 급분바 표의 "정답률" 같은 칸은 문항이 아니다.
- 제목으로는 본문인데 문항 표가 장의 표 절반 이상이면 기출로 고친다(`decided_by: content`).
- 급분바·본문 장 안에 문족이 들어 있으면(첫 문항 표부터 끝까지 문항 표가 2줄 이상이고 다른 표보다 많음) 그 부분을 `Ⅱ-문족. <제목> 안의 문족` 이라는 기출 장으로 떼어 `문족.md` 로 보낸다(`decided_by: nested`). 첫 문항 표 바로 앞 "2025년 문족" 같은 묶음 제목도 같이 간다.
- 시험: `npm test` (장 나누기·파일 이름 메타·강조 다듬기·표 풀기·강조요약·티로 맞추기).

큰 파일: 그림이 압축 안 된 BMP 인 족보는 풀면 256MB(kordoc 기본 한도)를 넘어서, `jokbo.mjs` 가 `KORDOC_MAX_UNZIP_MB=512` 를 기본으로 둔다(환경 변수로 이미 정했으면 그 값). 더 큰 파일은 `KORDOC_MAX_UNZIP_MB=1024 node jokbo.mjs …`. BMP 그림은 직접 풀어 다른 그림처럼 1600px webp 로 줄인다.

필요: Node 22. 엔진은 npm `kordoc`(본문), `@rhwp/core`(HWP 글자 색 읽기용 HWPX 변환), `sharp`(그림 줄이기), `jszip`.

Claude 스킬로 쓰려면 `skill/SKILL.md` 를 스킬로 저장한다(도구를 부르는 법과 결과로 공부하는 법).
